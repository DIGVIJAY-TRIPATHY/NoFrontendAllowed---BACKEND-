# NoFrontendAllowed---BACKEND-
A code repo for full backend without frontend for learning purpose


## 🛠️ Tech Stack & Dependencies

This project relies on the following dependencies and development tools to run efficiently:

### Production Dependencies (`dependencies`)
These are the core packages required to run the application in production:

* **[Express](https://expressjs.com/)** - Minimal and flexible Node.js web application framework for building APIs.
* **[Mongoose](https://mongoosejs.com/)** - MongoDB object modeling tool designed to work in an asynchronous environment.
* **[Mongoose Aggregate Paginate V2](https://www.npmjs.com/package/mongoose-aggregate-paginate-v2)** - A cursor-based custom aggregate pagination library for Mongoose.
* **[Bcrypt](https://www.npmjs.com/package/bcrypt)** - A library to help hash passwords for secure authentication.
* **[JSONWebToken](https://www.npmjs.com/package/jsonwebtoken)** - An implementation of JSON Web Tokens for user authorization and secure data exchange.
* **[Cookie-Parser](https://www.npmjs.com/package/cookie-parser)** - Middleware to parse cookies attached to the client request headers.
* **[Cors](https://www.npmjs.com/package/cors)** - Middleware to enable Cross-Origin Resource Sharing (CORS) with various options.
* **[Dotenv](https://www.npmjs.com/package/dotenv)** - Zero-dependency module that loads environment variables from a `.env` file.
* **[Multer](https://www.npmjs.com/package/multer)** - Middleware for handling `multipart/form-data`, primarily used for uploading files.
* **[Cloudinary](https://cloudinary.com/)** - SDK to easily integrate media uploading and management cloud services.

### Development Dependencies (`devDependencies`)
These packages are only needed for local development and testing:

* **[Nodemon](https://nodemon.io/)** - Utility tool that automatically restarts the node application when file changes in the directory are detected.
* **[Prettier](https://prettier.io/)** - An opinionated code formatter to maintain consistent code style across the project.
